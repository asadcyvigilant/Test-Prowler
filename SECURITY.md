# Security Policy

## Supported Versions

Security reports are accepted for the current `main` branch of this test repository.

## Reporting a Vulnerability

Use GitHub's private vulnerability reporting feature:
[Report a vulnerability](https://github.com/asadcyvigilant/Test-Prowler/security/advisories/new).

Include the affected file or configuration, steps to reproduce, and the potential
impact. Do not include live credentials or personal data. Do not report sensitive
security details in public issues.

The repository maintainer will review the report and coordinate any necessary
remediation. No response-time guarantee is provided for this test repository.
